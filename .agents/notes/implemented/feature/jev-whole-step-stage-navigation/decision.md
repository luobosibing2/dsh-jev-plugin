# Agent Note: Jev 完整 step 阶段导航

Status: implemented

## Problem

DSH 原生轨迹保存请求、模型输出、工具调用及返回，但用户需要逐条阅读才能辨认一轮内的工作目的如何变化。工具类型不能说明一次读取是在定位问题、辅助实现还是验证结果。把单次 Think 拆成自然段分类又会制造并不存在的步骤边界。

## Decision

现有 Jev 插件提供独立的“阶段导航”标签页，位于原生“轨迹”之后。它把一次用户输入到 Agent 结束、失败或中止视为一个 turn；每次模型步骤的完整 reasoning、对外文本、全部 ToolCall 和配对结果构成唯一分类单元。Jev 的类型化 Choice 为完整 step 选取六阶段之一，或选 `mixed`、`unknown`；程序只在同一 turn 内合并相邻、有效且同类的 step。原生工具错误、轮次中止和分类失败各自保留，不由阶段标签代替。

独立功能开关默认关闭，并控制标签页可见性。开启只显示页面，不调用 Jev；用户手动选择已结束轮或尚未分析的已结束轮后才发起判断。关闭隐藏入口、取消未完成分类并保留结果。授权历史读取固定一次持久事件范围；前序上下文可以有标记地限制长度，目标 step 保持完整，超出请求限制则跳过。输入在发送和记录前脱敏；凭据检查失败时不发送请求。Jev 公共 ledger 保存实际输入与原始回答，插件另存阶段、来源和状态以供刷新后复用。标签过期、失败或取消不被合并成阶段。

页面左侧按轮次和连续阶段导航，右侧展示可搜索的完整原文，并可查看分类输入与回答。该功能只读取 Session、写入辅助 Jev 记录，不改写主 Agent 执行或原始会话。它复用 DSH 公开会话视图扩展，不修改原生轨迹行；现有[会话节点装配](https://github.com/deepseek-ai/deepseek-harness/blob/d743267388641bc76f17c45ce8b4c231aed1d32c/.agents/notes/implemented/architecture/2026-08-09-client-conversation-node-assembly.md)继续拥有原生记录展示。[Delta Spec](delta-spec.md)保存完整行为与验收示例。

插件仓库的 GitHub 安装入口直接加载根目录 `runtime/`。源码与该目录构建结果随功能提交一同进入主分支；仓库 `AGENTS.md` 已把这一必要发布产物列为生成文件禁令的明确例外。

## Alternatives considered

**按 reasoning 段落分类。** 一次模型步骤的内部推敲会变成多个导航阶段，违背已确认的最小单元。

**整轮只给一个阶段。** 一轮可以在实现、验证和返工之间切换，单一标签丢失进展。

**改造原生轨迹行或加入生成式解读。** 原生轨迹缺少适合的公开行注解接口；Jev 的有限分类也不能等价替代自由文本叙述。独立标签直接把分类与原文相连。

**自动分析或只在页面内保存。** 自动触发会使浏览历史产生模型请求，页面级结果又会在重开后重复消费。显式手动触发和持久复用让调用范围可预期。

## Consequences

用户可以按阶段快速定位完整证据，且重复查看不会重复请求 Jev。每个已分析 step 的实际请求与回答可核对；未知、失败、取消和原生执行结果仍有独立状态。历史材料会发送到所配置的 Jev 服务，因而脱敏、授权读取、请求上限与失败时停止派发是本功能的持续约束。Jev 返回的 confidence 未经校准，不能当作分类准确率；同一材料在不同输入封装或提示下可能得到不同标签。用户日常 DSH profile 的安装和 Desktop 实机验收不属于此次合并的已验证结果。

## 边界与验证

功能分支 `codex/jev-whole-step-stage-navigation@835f69d` 经 [PR #3](https://github.com/luobosibing2/dsh-jev-plugin/pull/3) 合并到远端 `main@d6af739`；合并树与测试过的功能提交相同。冻结锁文件安装、完整构建、安装包内容检查及 26 个测试文件的 251 项测试通过。合并前审查补充了跨 Session 迟到请求隔离、多词凭据脱敏和凭据读取失败时的安全停止。

独立 DSH 0.1.7-rc.2 Web profile 安装了与构建字节一致的包。真实 Jev 对原第 8 轮材料的脱敏重编码副本完成 14/14 次单步判断，实际模型为 `jev-1.13.0`；结果为规划 1 → 实现 2–8 → 验证 9 → 实现 10–14，原生用户中止和最后一步工具错误保持独立。重启与浏览后仍为 14 个 operation、14 个 attempt，没有新增请求。原始完整会话另以只读方式核对 18 轮、250 步、309 对工具调用与返回；其余步骤未发送给 Jev，原日志未修改。该样本不证明阶段标签的普遍准确率。Web 中验证了多轮、搜索、长原文定位和 430 像素窄屏；用户日常 profile 与 Desktop 未安装验收。
