# Jev 完整 step 阶段导航：当前对齐

## 已确认

一轮交互对应 DSH turn：从用户输入进入本轮执行，到 Agent 正常结束、失败或中止。最小分析单元是完整 DSH step，即一次 Think / reasoning、对外文本及该次输出的全部 ToolCall；工具返回附作证据。一次输出中的多个 ToolCall 不拆成多个单元，没有 ToolCall 的最终回复仍是一个单元。禁止把 reasoning 自然段当最小单元。

Jev 对每个完整 step 返回一个阶段类别，采用输入解析、问题理解澄清、方案规划、实现与调试、审查验证、交付收尾，并保留 mixed / unknown。六阶段不要求齐全或单向推进。程序只在同一 turn 内合并连续且标签相同的 step；分类标签不表示工具成功或任务完成。

在“对话 / 轨迹”之后提供独立“阶段导航”插件标签页。采用已选定的 C 布局：左侧按轮次组织阶段，右侧定位对应原文；不同轮和同轮中再次出现的同名阶段分别定位。原生轨迹页不嵌入本功能，不保留原型的 A/B/C 选择器。

页面必须由真实记录和真实 Jev 响应驱动，不以手写分类、合成数据或人工解释冒充模型结果。保留原始标签、返回信号和可核对的输入输出，不根据低 confidence 自动改类，也不让生成模型补写分类理由。

作为现有 Jev 插件的独立默认关闭功能，复用连接和判断记录。开关同时控制入口可见性：关闭不显示“阶段导航”标签及页面；开启才显示，开启本身不触发模型调用。关闭正被查看的阶段页时安全回到原生会话视图，并取消本功能未完成分类；持久结果保留，重新开启后可查看和复用。由用户手动分析选中已结束轮，或分析本会话未分析的已结束轮；打开、浏览页面本身不产生模型请求。持久保存结果，按实际输入、规则和模型配置判断复用性；变化后标记过期，由用户主动重分析。

用户已授权实施、验证、推送功能分支、创建 MR 并合并主分支。Jev 仓库 PR [#3](https://github.com/luobosibing2/dsh-jev-plugin/pull/3) 已合并至 `main@d6af739`；用户日常 DSH profile 未安装或修改。本目录保存当前决定、规格和实际结果。
