# Jev 原生 Spill 预算协同增量规格

状态：已实现。[PR #48](https://github.com/luobosibing2/dsh-jev-plugin/pull/48) 于 2026-10-24 23:37（Asia/Shanghai）合并到 `main`，合并提交为 `49d0994d8454162138ad8b13aa4cc235e76143f3`，两项 PR CI 均通过。最终行为规格保留于此；决策与验证见 [decision.md](decision.md)。

## 目标与范围

原生 Spill 配有有限预算时，使 Jev 只对预算内、符合现有条件的较长工具日志做任务相关性去噪。超过预算的结果直接交给原生 Spill，避免先发起 Jev 判断或规则省略。Spill 未加载或未配置预算时，沿用现有 Jev 处理，不施加原生预算限制。

修改范围是独立 Jev 插件的通用日志与测试日志准入、直接相关验证、中英文说明和 tracked `runtime/`。DSH 源码只读；需要新宿主 API、扩大仓库修改范围或改变兼容范围时须先取得用户决定。已授权本地实现、必要验证及完成后的提交、推送和创建 MR；未授权合并、真实 profile 修改或付费调用。

Jev 实施基线为 `origin/main` 的 `c673f79298a29e7bcd45c9f09db217da253bbf4f`；隔离工作区为隔离工作区（位置未公开），分支为 `codex/jev-native-spill-budget`。宿主参考源码为 `deepseek-harness` 的 `d743267388641bc76f17c45ce8b4c231aed1d32c`；该源码快照不代表最新发布。

## ADDED Requirements

- **REQ-SPILL-001：采用的完整结果也须符合宿主预算。** 存在有限原生预算时，Jev 采用省略结果前按宿主相同估算规则检查最终模型可见内容，包括保留原文、省略标记、实际恢复提示及 `run_code` 外层结果。只有估算不超过本次实际生效的原生预算，且满足原有净缩减条件，才采用；不能用省略前后日志正文的字符差替代这项检查。已知无原生预算时，沿用现有净缩减与其他采用条件。
  - 验收：候选正文足够短，但加入实际恢复提示后超过预算时，不发布 Jev 替换；最终 Session 与后续模型请求保持宿主收到的原结果路径。恢复提示计入后仍在预算内且满足原有条件时，允许采用。

- **REQ-SPILL-002：预算和估算须来自受支持的宿主接口。** 读取当前实际生效的 Spill 策略预算，并复用宿主的内容估算；profile 覆盖须改变准入结果。不得访问私有宿主结构、猜测配置、复制基础 bundle 的固定预算，或把 token 数直接作为码点上限。接口不具备时，必须显式报告缺口，不能静默换成固定值。
  - 验收：同一原结果在两个实际预算不同的 profile 中，按各自预算进入或跳过 Jev；非 BMP 文本的判断与宿主 UTF-16 估算一致。最终依赖方案须同时由公开接口和兼容版本证据支持。

- **REQ-SPILL-004：已知无原生预算时保持原有 Jev 行为。** Spill 策略未加载，或已加载但未配置 `maxInlineTokens` 时，通用与测试准入继续按原有开关、长度、任务、判断、规则省略、保存和采用条件处理，不增加原生预算限制。`0` 是有效有限预算，仍按 REQ-SPILL-003 检查；无法可靠确定预算不等于已知无预算。
  - 验收：未加载策略与省略预算两种配置下，原有适用长日志仍可判断和采用，原有规则省略仍可发生；相同文本在有效预算 `0` 下直接跳过本次 Jev 处理。

- **REQ-SPILL-005：预算必须匹配本次实际参与的策略。** 使用公开的事件可见性规则确认本次工具执行适用的原生 Spill 策略。只有可唯一、稳定确认有限预算时，才按该预算处理；已知无有效预算时遵守 REQ-SPILL-004。无法可靠确定、多份可见有限预算策略，或执行期间策略激活、配置、可见上下文发生变化时，放弃本次 Jev 处理或采用，原决策继续宿主流程；不能猜选一份预算，也不能冒充无预算。必须识别同一实例重启等中间变化，不能只比较等待前后的最终配置。
  - 验收：跨 scope 不可见策略不影响本次预算；判断等待期间的策略重载、同实例重启、策略新增/卸载或 Loader 上下文刷新均防止晚到替换，且不重试工具或判断。后续稳定执行读取变更后的真实配置。

## MODIFIED Requirements

- **REQ-SPILL-003：原生预算决定本次 Jev 准入是否适用。**
  - 之前：符合工具、任务、最小长度等条件的结果可先经过 Jev 判断或规则省略，之后才由原生 Spill 处理；现有集成用例允许 Jev 原文保存与后续 Spill 保存各发生一次。
  - 现在：存在有限原生预算时，在任何本次准入判断或规则省略前检查 Jev 当前收到、尚未经该 spill-policy 裁剪的完整模型可见结果。其估算超过实际预算时，直接返回原有决策，不调用 Jev、不作规则省略，由后续原生 Spill 处理。估算小于或等于预算时，继续应用所有现有适用检查；只有符合条件且足够长的材料才调用 Jev，短材料原样通过。已知无预算时遵守 REQ-SPILL-004。这里的“原结果”不保证是完整进程输出，上游工具输出限制仍可能已生效。
  - 验收：预算以下与等于预算的适用长日志可以进入现有判断；预算以上的通用、测试和规则可省略日志均产生零次 Jev 调用、零次 Jev 原文保存，原生 Spill 接收未经 Jev 处理的结果。

## REMOVED Requirements

无新增接口、配置项或持久化格式的删除。旧的“先 Jev 缩减，再由 Spill 裁剪同一超预算结果”行为由 REQ-SPILL-003 替换，不再作为预期结果。

## 保持不变的行为

通用日志与测试日志准入保持独立且默认关闭。现有工具支持范围、根 Agent 限制、已改写内容保护、完整输出请求保护、失败状态处理、已知测试格式和分支选择保持不变。测试日志仍保护失败、摘要、命名或慢测试及控制标记；未选择的原文保持字节与顺序。

完整序列化 Jev 请求仍受自己的码点预算约束，不用 Spill 预算替代。保留证据必须完整；未提交的候选不能作为已展示证据。候选数量、任务材料、概率阈值、超时、取消和 `canAdopt` 当前任务版本检查保持不变。

省略前仍保存 Jev 实际收到的原结果，并提供可用的宿主 locator 与恢复提示。原文保存不保证恢复上游未交给 Jev 的内容。原有最小净缩减码点数及比例继续生效。规则省略与语义判断各自的记录、最终结果回执及 Session 权威关系保持不变。

## 输入、默认值、顺序与优先级

输入是本次符合支持范围的模型可见工具结果，包含 `run_code` 显式日志之外的保留后缀。原始结构化工具值、状态和 PTC 子调用不变。富媒体仍按已有适用性检查跳过，不扩展支持范围。

宿主预算使用当前实际生效的 `maxInlineTokens`；不新增 Jev 专属 token 预算默认值。参考宿主的单文本块估算是 `ceil(text.length / 4) + 4`，其中 `text.length` 是 UTF-16 长度；这只是当前宿主估算事实，不是精确 tokenizer，也不授权复制估算实现。基础 bundle 的 12500 不是不可覆盖常量。

Jev 当前默认最小长度为通用 6000、测试 4000 个 Unicode 码点；请求预算 48000 码点、任务材料预算 12000 码点、最长等待 4000 ms、省略概率阈值 0.7、最小净缩减 300 码点及 0.1 比例保持不变。profile 已配置值继续优先于这些默认值。

实际文本处理位置保持在原生 Spill 裁剪之前，不增加顺序模式。超预算跳过优先于本次 Jev 判断与任何规则省略；预算内的通过只表示继续检查，不自动触发判断或采用。原生预算的等号沿用 `<=` 通过语义。

宿主允许预算为非负整数，`0` 是有效预算，不得与未配置混为一谈。宿主未加载策略，或加载时省略 `maxInlineTokens`，不会注册该策略的裁剪回调；这两种情形下沿用现有 Jev 处理，不施加原生预算限制。不得由“存在原文保存服务”推断“策略已启用”。

## 失败与回退

超预算是正常不适用：原决策原样交给宿主，不发起 Jev 请求、不先做规则省略。最终替换超过预算或未满足净缩减时，放弃采用，保持原结果的宿主路径。策略预算无法可靠确定或执行期失效时，按 REQ-SPILL-005 保守保持原结果；该情形与已知无预算分别处理。

Jev 超时、传输失败、无效或不完整答案、取消、插件卸载、Agent 不再活跃或任务版本变动继续沿用当前保持原结果的语义，不增加自动重试或人工问题。原文保存失败仍不能发布省略结果。

已知未加载策略或未配置预算时，按 REQ-SPILL-004 延续 Jev 行为。不能可靠确定是否存在预算或取得其实际值时，按 REQ-SPILL-005 保守放弃本次处理；不得把这一情形冒充已知无预算、静默写死数值或扩大兼容承诺。

## 端到端传递

工具结果进入现有 `tools/post-execute` 准入位置后，根据本次执行所见且保持稳定的实际原生预算，检查尚未被该策略裁剪的模型可见结果。超预算直接进入原生 Spill；预算内或已知无预算的适用长日志继续形成完整任务、候选与保留证据请求，完成判断与当前任务采用检查。

需要省略时，保存实际原结果，将实际 locator、恢复提示、标记和外层后缀一并纳入最终预算及净缩减检查。被采用的结果进入原生结果路径、最终 `tool/result`、Session 持久化与后续主模型请求；这些位置对实际文本的记录必须一致。恢复入口能读回 Jev 收到的原结果。

## 对外契约

本功能改变配有有限原生预算时的可观察准入范围：只处理预算内较长日志，超预算输出交给原生 Spill；已知无原生预算时沿用原有处理。现有开关、Jev 请求语义、工具结果结构化值和 Session 事件格式不变；不增加顺序配置项。

Jev 当前声明并验证的宿主版本包括 `0.1.7-rc.1`、`0.1.7-rc.2`、`0.2.0-rc.1`、`0.2.0-rc.2`、`0.2.1-alpha.2`、`0.2.1-alpha.3`、`0.2.1-rc.2`。七版均有实现所需的公开估算、运行配置、过滤和生命周期事件；本次保持版本范围。源码与发布接口核查只支持可行性，不替代新增行为的兼容测试。

中英文当前说明与 tracked `runtime/` 必须同步实际实现。不得据预算启发式、确定性夹具或缩短文本宣称任务准确率提升、真实 token 节省或自然任务收益。

| 预算以下 | 适用长日志，估算为 T，实际预算 B 且 T < B | 工具返回 | 继续现有适用检查，可调用判断；仍须满足全部采用条件 | REQ-SPILL-002、REQ-SPILL-003 |
| 等于预算 | 同类日志，T = B | 工具返回 | 沿用 `<=` 通过，不因等号跳过 | REQ-SPILL-003 |
| 超过预算 | 同类日志，T > B | 工具返回 | 零次 Jev 判断、零次 Jev 原文保存；原生 Spill 接收原结果并执行本身策略 | REQ-SPILL-003 |
| 规则候选超预算 | 测试日志含本可按规则省略的进度或重复失败详情，T > B | 工具返回 | 不先做规则省略，交给原生 Spill 的文本保持原样 | REQ-SPILL-003 |

| 小输出 | T <= B，但小于当前分支最小长度 | 工具返回 | 零次 Jev 判断，原文通过 | REQ-SPILL-003 |
| 完整 `run_code` 结果 | 显式日志单独在预算内，含外层后缀的整个结果超预算 | 工具返回 | 按整个模型可见结果跳过，不只估算日志片段 | REQ-SPILL-002、REQ-SPILL-003 |
| 预算内采用 | 适用长日志，完整请求在预算内，判断明确，保存成功，最终结果在宿主预算内且达到原净缩减门槛 | 判断返回 | 发布省略结果，原文能恢复，Session 与后续模型请求记录相同最终文本 | REQ-SPILL-001、REQ-SPILL-003 |
| 恢复提示导致超预算 | 替换正文在预算内，但实际提示、标记或后缀使最终估算超过 B | 形成最终结果 | 不采用，不能删掉恢复提示绕过预算 | REQ-SPILL-001 |

| 完整请求与保留证据 | T <= B，但完整序列化请求或必要保留证据无法符合现有请求预算 | 准备判断 | 保留现有无语义省略行为，不裁掉证据来迁就请求 | REQ-SPILL-003 |
| 取消、超时或失效 | 请求已发出，之后取消、等待到期、任务版本改变或 Agent 退出 | 收到或等待判断 | 沿用原语义，无晚到替换，无重复工具执行 | REQ-SPILL-001、REQ-SPILL-003 |

| 零预算 | 实际配置 `maxInlineTokens: 0`，工具有非空文本 | 工具返回 | 视为有限预算，跳过 Jev 判断及规则省略，交给原生 Spill | REQ-SPILL-003、REQ-SPILL-004 |
| 判断期间改预算 | 有限预算允许进入 Jev，期间通过正常配置更新重载策略 | 旧判断完成 | 放弃本次替换；本次宿主回调保留自身预算，后续稳定执行读取新配置 | REQ-SPILL-002、REQ-SPILL-005 |
| 重启或临时变化 | 判断期间同策略实例重启，或新增/卸载可见策略后恢复原状态 | 旧判断完成 | 中间变化仍导致本次失效，不因最终身份和值相等而采用 | REQ-SPILL-005 |
| 不可见策略 | 另一 scope 有不同预算的原生策略，本次事件不可见 | 本次工具返回 | 不把另一 scope 的策略预算套给本次结果 | REQ-SPILL-002、REQ-SPILL-005 |
| 多份可见有限预算 | 本次事件可见不止一份有限预算原生策略 | 工具返回 | 不选首个或最小值，不调用 Jev 或规则省略，原决策继续宿主流程 | REQ-SPILL-005 |
| Loader 上下文刷新 | 执行期间 Loader 正常刷新相关事件可见上下文 | 准备判断或采用 | 本次保守失效，不根据可能错配的配置进行省略 | REQ-SPILL-005 |

## 非目标

不调整为 Spill 先裁剪再交给 Jev，不增加顺序模式，不在超预算输出上做首尾预览判断。不重写候选规则、概率策略、请求预算或已有恢复协议；不改其他 Jev 功能。不修改 DSH 宿主源码、变更兼容范围、发布软件版本、合并、修改真实用户 profile 或发起付费请求，除非用户随后明确授权。创建 MR 已获授权。

## 决策闭合

- 已确认：七条当前规则、Jev 实际处理位置、超预算零判断及零规则省略、等号通过、复用实际预算与宿主估算、完整替换计入预算、原有保护与语义定位均来自本次实施交接；用户另要求生成本 Delta Spec，并明确未加载 Spill 或未配置预算时沿用现有 Jev、不受原生预算限制。
- 代码事实：实施基线中准入尚未检查原生预算；默认省略阈值为 0.7；现有集成测试允许 Jev 与 Spill 两次保存。详见 [准入源码](https://github.com/luobosibing2/dsh-jev-plugin/blob/c673f79298a29e7bcd45c9f09db217da253bbf4f/packages/jev/src/output-admission.ts#L217)、[原集成场景](../../../../../packages/jev/tests/output-admission-integration.test.ts#L397) 和 [版本清单](../../../../../scripts/validation/compatibility-versions.mjs)。七个兼容版本的发布包均公开 `@deepseek-ai/dsh-token-meter/estimate`，没有专用 Spill 预算查询 API，但具有公开 Cordis 运行配置、事件过滤及同步生命周期通知。单独读取当前配置不足以匹配某次在途回调；结合执行所见策略及连续稳定性可保守处理，详见决策依据。宿主及发布包均只读核查，尚未执行新行为测试；DSH 引用是跨仓库参考快照。
- 未决问题：无。REQ-SPILL-005 是为满足本次实际预算要求、依据公开宿主时序采用的保守实施约束，不扩大宿主修改范围。最终正确性仍须以本地行为验证确认；若实施发现公开接口不能满足这些约束，应报告实际缺口而非降低验收。
