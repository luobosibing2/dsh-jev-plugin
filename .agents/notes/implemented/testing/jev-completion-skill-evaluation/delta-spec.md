# REQ-JEV-CS 增量规格：完成核查与技能选择量化实验

Status: implemented。两项实验维护入口和网站资料已分别通过PR #6、PR #7合入main；本规格拥有固定条件与验收，理由见[Decision](decision.md)。

## 目标与范围

测现有completion-check与skill-selection的实际触发、判断、采用及任务结果，复用已合并DSH/Pier隔离与证据导出。新增本地实验驱动、固定案例和离线分析，不改变插件或DSH产品行为。首批最多26个独立trial：完成核查六类固定记录各baseline/开启一次；技能选择六类各baseline/开启一次；一题原始DeepSWE任务baseline/completion_check各一次。固定记录仅调用真实Jev，主模型为明确标识的本地脚本化provider；技能和原始编码配对调用真实DeepSeek/Jev。Sol实现与无费验证，主代理唯一执行收费步骤。

## 输入、默认值、顺序与优先级

先固定记录六对，再技能六对，再原始编码一对；每例baseline后开启，仍存在缓存/顺序限制。固定脚本case的初始证据与后续脚本均在收费前冻结，成功率只解释为指定状态上的判断与机制表现；真实编码允许模型自主轨迹，不能要求baseline制造错误。技能空目录必须是真正完整空snapshot；相关集合空时排名召回N/A，任务结果仍可验收。用户直接指令、原生作用域与产品暂停优先于实验追加。

## 失败与回退

镜像、原生配置、证据导出或fixture入口不成立时在收费前修复实验材料并重新冻结，不改产品行为。收费后固定输入不再按答案调节；语义错误、排名不佳、不加载技能、补做无效均保留为结果。服务/人工/证据阻塞停止追加，报告已完成范围与费用未知；不会以绕过产品guard恢复为默认下一步。槽25暴露的结果目录发现错误允许一次局部采集修订：原采集器仅匹配受控案例的`task__*`目录，漏读已完整存在的原始编码trial。保留修订前锁、报告、停止状态和采集源码，仅修正trial路径发现，记录新旧哈希及精确diff，确认其余冻结输入不变；无费复核缺失/多个trial仍拒绝、已完成24槽指标不变、槽25全部完整性及费用检查通过后，由root显式恢复槽间状态并执行未开始的槽26。不得重跑槽25，不修改任务、模型输入、真值、配置或其他停止条件。

## 端到端传递

后续技能第1槽正常完成后，第2槽启动前发现输入枚举误把`slots/*/pier.stdout.txt`和`pier.stderr.txt`当作新增冻结输入。允许一次只涉及冻结输入枚举的局部修订：保留旧锁、源码、报告、状态和启动失败记录，明确只冻结预声明job等输入而不冻结生成的运行日志；不得修改任务、模型输入、fixture、真值、profile、价格或既有结果。无费验证输出日志生成后锁仍稳定、修改job仍拒绝、已完成第1槽分析逐项不变；只更新对应源码哈希并记录其他冻结项相同。root审查后可从尚未开始的第2槽继续，不重跑第1槽。编码第2槽的产品证据裁剪/人工交互停止不在此修订范围内，编码第3/4槽保持未开始。

完成固定记录由profile中的本地LLM adapter产生合法模型块，原生AgentLoop执行工具、停止并触发completion，再由真实Jev判断和原生steer决定是否进入预先固定后续分支。真实编码沿原始任务与独立verifier执行。技能由原生filesystem发现与pre-step目录发布进入Jev相关性判断，主模型通过原生skill_catalog/skill读取并按任务交付。Session、plugin ledger、工作区事实与独立oracle共同确定结果。

## 对外契约

本次是本地实验与报告，不新增公开产品API或通用评测SDK。真实模型路由和脚本化模型身份均显式记录，不能通过原有smoke的fixture_module入口偷偷保留mock Jev。正常DSH凭据服务或受保护stdin供给专用child环境，不把密钥写进清单、命令日志或Git；公开发布需要后续对应授权。规划三文件保持本地主仓proposed，直到实际授权合并。

## 决策闭合
