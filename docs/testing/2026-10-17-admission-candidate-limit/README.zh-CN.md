## 真实任务与证据

新的 headless profile 安装同一 tarball，只开启通用日志准入，保留原有默认值，包括 48 个候选和 48,000 码点的完整序列化请求预算。真实主模型接到任务：仅使用一次原生 `bash` 执行 `node build.mjs`，随后报告构建标记、合计值和退出状态。受控脚本实际导入并校验 24 个 ESM 模块，写入 24 份副本和校验清单，按交替的产物／进度分组输出日志。

任务用时 **4,601 ms**、exit 0，实际产生 **2 次 DeepSeek Flash 请求、1 次 Jev 1.13.0 请求和 1 次原生 Bash 调用**。三次请求均收到 HTTP 200。独立检查确认 24 份产物的校验和全部一致，合计值为 **300**；最终回答报告了构建标记及合计值，持久轮次以 `completed` 结束，无 Agent 错误或人工交互。

完整 Jev wire 输入与业务 ledger 输入一致：**24 个问题、24 个候选、25 段逐行对应原文的保留证据，请求 34,360 个码点，没有未提交候选**。持久 Session 恰有一条非错误工具结果，其文本与原日志的 SHA-256 同为 `723954b2557d8c897936e99ee9f2a073b31302f27e2004603b47b24666f44205`。已有凭据文件仅由原生 provider 读取，前后字节一致；没有修改已有用户 profile。

首轮真实任务在 HTTP 派发前因验证配置失败而停止：官方 headless 模板默认禁用 credentials 行，首次 overlay 只配置路径而未启用。仅在验证 overlay 补充 `disabled: false` 后，使用新证据目录完成成功任务。首轮配置失败独立保留，没有为此修改产品代码。

## 边界与验证

本轮只有一个受控任务，使用真实服务、原生工具和实际文件操作，不建立自然任务准确率、稳定节省比例、延迟或普遍可靠性。本次真实输出没有省略，未验证真实省略后的原文恢复；确定性测试覆盖该路径。

两条 DeepSeek 被动 SSE clone 在收集响应元数据时记录 `AbortError`。原生任务已成功结束；这不代表产品流失败，也不能作为完整 DeepSeek wire 捕获。Jev 响应完整捕获。HTTP 状态、实际判断输入、持久工具输出和文件事实分别核对；成功任务后没有追加付费请求。

本任务专用 runner、完整命令和原始证据保留在本机 ignored `.artifacts/`。公开文件仅含聚合事实与哈希，不包含凭据、认证地址、原始 provider 包或 Session 捕获。
